# Monesh Rathod — Portfolio (moneshrathod.github.io)

## Folder Setup
1. Place index.html, style.css, and script.js in the root of your moneshrathod.github.io repository.
2. Copy the assets/images/ folder from monesh-portfolio-updated.zip into the root so the project photos load at:
   - assets/images/rf-amplifier.jpg
   - assets/images/botsdr.jpg
   - assets/images/ethernet-gateway.jpg
   - assets/images/ev-cluster.jpg
   - assets/images/fall-detection-pcb.jpg
3. Commit and push to GitHub:
   git add .
   git commit -m "Update portfolio website"
   git push origin main
